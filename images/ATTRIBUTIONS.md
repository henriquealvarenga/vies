# Atribuições de imagens

Esta pasta armazena imagens utilizadas no site. Todas as imagens
incluídas devem ter **proveniência e licença documentadas** abaixo.

## Princípio

Nenhuma imagem é incluída no repositório sem verificação prévia de
**domínio público** ou de **licença compatível** (Creative Commons CC0,
CC-BY, MIT, GPL, ou autorização escrita do autor).

### Formato sugerido

```
### nome-do-arquivo.png
- **Origem**: URL completa
- **Autor**: Nome do autor / instituição
- **Licença**: CC0 / CC-BY-4.0 / domínio público / etc.
- **Data de acesso**: AAAA-MM-DD
- **Uso no site**: página(s) onde a imagem aparece
- **Modificações**: cortes, redimensionamentos, traduções de legendas, etc.
```

## Imagens externas comumente utilizadas em epidemiologia

Para referência futura, fontes confiáveis de imagens com licença
permissiva:

- **Wikimedia Commons** — verificar licença individual de cada imagem.
- **CDC Public Health Image Library (PHIL)** — domínio público (EUA).
- **NIH / NLM Open-i** — imagens biomédicas com filtro por licença.
- **Unsplash, Pexels, Pixabay** — licenças generosas para fotografia
  genérica (não substituem fontes médicas para conteúdo técnico).

## Logos e marcas comerciais

Logotipos institucionais (Anthropic, Google, MIT, etc.) **não** devem
ser incluídos no repositório, mesmo quando livremente disponíveis para
download. Citá-los textualmente é geralmente suficiente.
